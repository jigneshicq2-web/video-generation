# RecurPost Meta Ads: Instagram DM Automation (keyword triggers + CTA buttons)
## 10 variations + AI image-generation prompts

---

## SETUP

Use `00-master-style-guide.md`: upload the right logo, paste **Block A** once, then paste the variation prompts below one at a time. Check every output against **Block C** in the same file.

**Claim guardrail:** only these facts are used, as confirmed in public sources: **Instagram DM automation that fires on keywords** and sends replies with **custom CTA buttons**.
- These ads use **DM keywords** ("DM us 'PRICE'") as the trigger.
- **Comment-to-DM triggers** (someone comments "LINK" and gets a DM) are only in V8, which is flagged. Verify RecurPost supports them before running it.
- No conversion-rate claims.
- Show Instagram only via a **generic DM UI** (no Instagram logo, no Meta trademarks), which is also safer for Meta ad review.

**Strategic note:** for agencies, this is also a **service they can sell to clients** (V6). That's the strongest angle here, because it's about making money rather than saving time.
